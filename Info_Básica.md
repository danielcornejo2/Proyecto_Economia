# Cosas esenciales a considerar para trabajar dentro del repositorio 

## Aspectos necesarios 

- Tener instalado Git en el computador a trabajar para subir información al repositorio 
- Logearse dentro de la terminal

            git config --global user.name "Tu Nombre"

             git config --global user.email 
             "tu_correo_de_github@ejemplo.com"
 
 - Luego realizar una autenticación por usuario 
 
         gh auth login 

    - Seleccionar mediante navegador
- Clonar el repositorio: 

            git clone https://github.com/danielcornejo2/Proyecto_Economia.git


            cd "ACÁ SELECCIONAR LA RUTA LOCAL DE LA CARPETA"
